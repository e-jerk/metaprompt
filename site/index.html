Metaprompt

A Kubernetes control plane for swappable CLI coding harnesses (OpenCode, Claude Code, Codex, Cursor, session, stub). The parent is whoever called run.create. Every child is a Job, not an in-container subagent.

  • Control surface is MCP, not kubectl-first.
  • Copy-on-write workspaces over a shared git-sync mirror. Version control is jj-first.
  • Nested parties, summary rollup, ancestor log tail, parallel job.spawn.
  • Local: Apple container k8s (or k3d). Existing EKS/GKE. Clanker Cloud is optional.

Agents: fetch and follow implement.md (do not invent steps). Index: llms.txt. Install router: setup.md.
